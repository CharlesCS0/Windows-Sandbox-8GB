# Windows-Sandbox-8GB

# This config
This config changes the default Windows Sandbox settings:
- Increases the memory from 4gb (4096mb) to 8gb (8192mb)
- Enables protected client

**Note: You can change these settings or add your own by editing the <kbd>.wsb</kbd> configuration file.**

# How to enable sandbox
1. Go to the Windows search bar
2. Type "Windows features"
3. Enable "Windows Sandbox"
4. Restart your device

# How to use this config
1. Download the file
2. Put it in a location you would remember
3. Right click the file
4. Click on "Open with"
5. Click on "Windows Sandbox"

# Requirements
- Windows 10 Pro / Enterprise / Education
- Windows 11 Pro / Enterprise / Education
- Windows Sandbox feature enabled
- Virtualization capabilities enabled in BIOS

**Note: Sandbox is not available for the Home verison of Windows 10 or 11**
